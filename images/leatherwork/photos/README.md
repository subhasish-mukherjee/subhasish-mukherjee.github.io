# Add leatherwork images here

Put your `.jpg` or `.webp` leatherwork photos in this folder. Use lowercase,
hyphenated filenames such as `01-bifold-wallet.jpg`.

Then add an entry for each image to [`../gallery.json`](../gallery.json). The
instructions and an example are in the [parent README](../README.md).

Phone photos can contain embedded GPS coordinates. Have them sanitized before
publishing; Codex will check this when you ask it to add or publish new images.
